## 3. Stockage
- `window.claude.use` présent (artefact) : en ligne, sans écran de bienvenue. `db=await claude.use('db')`, `user`, `assets`, `downloads` idem (échec = absent) ; `await user.id()` ; `db.collection(ch).get()`→`{size,docs:[{id,data()}]}` ; `.doc(id).set(o)/.delete()` ; `db.doc(ch).get()`→`{exists,data()}` ; `assets.upload(blob)`→`{id}` lu via `/_blob/{id}` ; `dl.save({filename,data:blob})` (`code==='declined'` = annulé). Chemin `data/users/{id}/ws` : doc `meta/settings` + une collection par type ; n’écrire que les docs modifiés/supprimés (cache JSON) ; relance 800 ms si `code==='unavailable'`. Assets : pdf, images, mp4/webm, txt/csv/md/json, 20 Mo, sinon refus expliqué.
- Sinon écran de bienvenue (carte, logo 40 px) : « Dans un dossier de mon ordinateur » (File System Access, OneDrive recommandé, désactivé avec explication si non supporté ; données existantes ouvertes) ou « Dans ce navigateur » (IndexedDB). Choix + handle mémorisés en IndexedDB, **sous une clé propre au chemin du fichier HTML (`location.pathname` décodé en file:, origine + chemin sinon) : tous les fichiers file:/// partagent le même stockage navigateur, donc une copie du HTML placée ailleurs ne doit JAMAIS se reconnecter seule au dossier ou aux données d’une autre copie et affiche l’écran de bienvenue (avec la mention « Ce choix est mémorisé pour ce fichier uniquement : une copie placée ailleurs vous le redemandera. »). Même règle pour la copie de secours (récupération) et la date de dernière sauvegarde auto** ; sans permission au démarrage : écran « Accès au dossier requis » (Autoriser / Choisir un autre emplacement).
- Dossier : `data.json`, `images/`, `files/` (≤ 200 Mo), `data.bak.json` (data.json précédent, à la 1re écriture de session), `automatic_save/automatic_save_AAAA-MM-JJ_HH-MM-SS.json` toutes les 10 min si modifié (garder 3 récents + le plus récent de chacun des 7 derniers jours), `points_de_retour/` (manuels). Mode navigateur : mêmes instantanés en IndexedDB. Images = fichiers référencés par `data-file`, affichés via blob URL.
- Enregistrement 600 ms après modification, flush en arrière-plan ; état en barre du haut « Enregistrement… » puis « Enregistré » (« Gardé dans le navigateur » seulement si l’écriture dossier échoue). Copie de chaque état en IndexedDB avant écriture ; au démarrage, copie plus récente et différente → modale Récupérer / Ignorer. Permission perdue (vérifiée avant écriture et au retour sur l’onglet) → une seule modale Autoriser l’accès / Plus tard (5 min). data.json absent/illisible → dernier instantané puis data.bak.json, original gardé en `data.illisible.json`, message après démarrage.
